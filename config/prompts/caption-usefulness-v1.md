## Search usefulness of a caption set (1–5)

Question: if the owner typed a natural search for this photo, how well would this caption and its tags let it be found, and found for the right reasons? Rate the caption + tags together, against what is actually in the photo. Ignore style and length: a longer caption scores higher only if the extra words are things someone would search for.

First note the photo's searchable facts, in this order of importance:
1. the main subject(s) (who/what, roughly how many people, animals, key objects);
2. the setting or scene (beach, kitchen, mountain path, city street, indoors/outdoors);
3. the activity or occasion (skiing, birthday, wedding, eating) when there is one;
4. anything distinctive someone would remember: legible text, a landmark, black-and-white, a film scan or old print, night, snow.

Then rate:

- **5 – excellent.** Every fact in 1–4 that the photo has is findable in the caption or tags, in plain words a person would type. Nothing wrong or invented.
- **4 – good.** The main subject and setting are findable; one secondary fact (activity, text, B&W/film nature, a distinctive detail) is missing or vague. Nothing wrong that would mislead a search.
- **3 – partial.** The main subject is findable, but the setting or the activity is missing or vague, or there is one wrong detail that would put the photo under a wrong search (e.g. "lake" for a sea, "toned" for a colour photo).
- **2 – poor.** Only a generic description ("a photo of people outdoors") or the main subject is misidentified; a searcher would rarely reach this photo by describing it.
- **1 – useless.** No caption, or the caption describes something else, or it is so wrong or vague that no natural search would find this photo.

Rules: wrong facts weigh more than missing ones (a wrong fact misleads; a missing one only fails to help). Invented specifics (a guessed place, event or relationship) count as wrong. Never identify people.
